Android installation (easy method)

  1. Download this HTML file to your phone.
  2. Open it from Downloads using Chrome or another browser.
  3. Use the browser menu “Add to Home screen” if offered. For a more reliable installable app/PWA, the files must be hosted on HTTPS with a manifest and service worker.
  4. Keep a JSON backup in Google Drive or your file manager.

This single-file version is not an APK and cannot fully install like a native Android app. The browser may treat local-file storage differently between browsers.
